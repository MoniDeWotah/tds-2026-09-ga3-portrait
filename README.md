# Ngozi Okonjo-Iweala reconstructed portrait

A glTF 2.0 portrait reconstructed from the assigned 2008 IMF photograph.

The face uses image-derived MediaPipe landmarks and a projected photograph texture. Skull, neck, headwrap depth and shoulders include geometric estimates because one photograph does not determine hidden surfaces.

Reference photograph: https://commons.wikimedia.org/wiki/File:Okonjo-Iweala,_Ngozi_(2008_portrait).jpg

The photograph is attributed to the International Monetary Fund and is documented as public domain by Wikimedia Commons. The model and viewer authored for this project are released under CC0 1.0. No credentials, student records or game receipts are included.

## Low-poly Blender variant

`ngozi-lowpoly.glb` is a separate 6,341-triangle, 464,000-byte variant made in Blender 5.1.1. The measured face and its matching skull boundary are preserved; support geometry is simplified. `lowpoly.html` provides an interactive viewer. Front, side and three-quarter views were reviewed locally. Hidden geometry remains estimated; no offline likeness score is claimed. The original model remains available.
